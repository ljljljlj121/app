# 多模态情感数据采集 Android App

此工程将原采集端的硬件输入改为 Android 手机上的前置摄像头和麦克风；样本上传、情绪标注、复核锁/盲审与编号重排继续调用现有远端 API。本工程不包含也不修改服务器代码。

## 使用

1. 将 `robot-prize-data-collection.apk` 安装到 Android 手机上。
2. 首次进入时允许摄像头权限；使用“音视频互动”时还需允许麦克风权限。
3. 默认远端地址为 `http://183.62.69.210:9004`，首次使用需在设置中填写上传令牌。若服务器配置不同，在“设置”里修改地址和令牌。云端识别页需填写 API Key，源码不内置令牌。设备编号用于复核锁，会在首次启动时生成并保存在本机。
4. “纯表情”录制 5 秒视频并生成静音 WAV；“音视频互动”在 5 秒内等待开口，检测到语音后按设置的停顿上限结束，最长 60 秒。默认 RMS 门槛为 200，开口和后续停顿检测全程使用本次录制的设置值，不再自动降至 50。设置在开始录制时读取，修改后下一次录制生效。停顿结束后直接裁切：裁切时长 = 设置的停顿上限 −min(1 秒, 停顿上限 /4)。不再检查末尾音量或是否接近零，也不以实际等待时间替代设置值。默认 1.5 秒停顿裁掉 1.125 秒；6 秒停顿裁掉 5 秒。音频与原视频同步裁切，合成不再按较短轨道截尾；纯表情、无人开口和最大时长停止均不裁切。音视频补偿仍可在设置中调整，已保存的自定义门槛继续保留。
5. 预览根据实际录制区域的宽高等比缩小：竖屏最高 300dp，横屏最高 190dp，均不能超过可用高度。横屏顶部栏紧凑，左侧预览顶端对齐，右侧操作区域独立滚动；状态栏、刘海和导航条由安全区域组件避让。前置相机预览与录制均镜像，预览缩小不改变录像分辨率。开启系统自动旋转后支持横屏。复核页有播放/暂停、从头播放和重试加载按钮，加载/播放超时显示错误。
6. 上传文件统一使用 file:// 或 content:// URI，兼容裁切视频模块返回的绝对路径。上传失败时本次文件保留在应用缓存中，可点“重试上传”或“丢弃并重新录制”，无需重复录制；请保持应用打开，待上传状态暂不跨重启保存。
7. 上传后选择情绪、标记无效或跳过；“盲审复核”可以加载待复核/全部样本。编号重排会修改远端数据，只有在二次确认后才会执行。

## 构建

本机已准备便携式工具时，可以在项目根目录运行：

```powershell
cd C:\Users\HONOR\Desktop\app
powershell -ExecutionPolicy Bypass -File .\build-apk.ps1
```

脚本使用 `.build-tools` 中的 Node.js、JDK 和 Gradle 缓存以及 `.android-sdk`，默认生成适用于现代 ARM64 安卓手机的 Release APK。需要其他架构时传入 `-Architectures "armeabi-v7a,arm64-v8a,x86,x86_64"`。

```powershell
npm ci
npx expo prebuild --platform android
cd android
.\gradlew.bat assembleRelease
```

APK 输出在 `android/app/build/outputs/apk/release/app-release.apk`。

## 云端循环语音情感检测（1.0.12）

点击顶部第三个页签“云端情感识别”进入独立页面，再点击“开始循环语音检测”。流程循环执行：无限等待开口 → 检测到语音后录制 → 停顿 0.6 秒后结束 → 上传识别 → 显示结果 → 自动返回监听。按“停止检测”结束整个循环；进入后台也会停止。停止后保留最近一次识别结果。

上传识别期间暂停监听，不并行录制、不创建片段队列。等待期间只计算麦克风音量，不录制视频或持续保存音频。每段讲话最长 15 秒，等待时间不计入。使用 RMS 音量门槛，可在独立页面设置。单次网络识别失败会提示错误并返回监听，采集设备错误则停止并报错。

原有数据集采集及复核保持原逻辑。保留 480p / 500kbps 录像、请求参数复用及耗时显示。
